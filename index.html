How this platform works

  1. Register as a user (only “Bajaish” can be admin).
  2. Calculate your carbon credits using trees or land area.
  3. Create posts to list your credits or projects.
  4. Buyers and project owners can like, comment, and chat in real-time.
  5. Admin can moderate users and listings from the admin panel.
